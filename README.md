# Semantic Search Engine

A production-oriented Semantic Search Engine built completely from first principles.

This project is part of a World-Class RAG Engineering roadmap where every component is implemented and understood from scratch before using higher-level frameworks.

---

## 🎯 Project Goal

Build a semantic search engine capable of retrieving the most relevant document chunks using vector embeddings and similarity search.

This project intentionally avoids frameworks such as LangChain in the early stages to focus on core engineering concepts.

---

## 🚀 Features (Current)

- PDF Text Extraction
- Modular Architecture
- Vector Embeddings
- FAISS Vector Store
- Semantic Similarity Search
